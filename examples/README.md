# SDD Framework — Worked Examples

This directory contains a complete, end-to-end SDD run for a fictional project.
It shows exactly what the framework produces at each command and how the traceability
chain (BO → BR → FR/NFR → UC → STORY → TASK) flows through the documents.

## todo-api

A `backend-service` pilot-scope run for a REST API that manages todo tasks.

**Tech stack:** TypeScript / Express / PostgreSQL  
**Scope:** pilot  
**Commands run:** /specify → [GATE-1] → /validate → /analyze → /clarify → /plan-arch → /plan-hld → /task → /implement → /release

### Traceability at a glance

```
BO-001 Revenue / BO-002 Retention
  └─ BR-001 CRUD tasks / BR-002 Priority / BR-003 Due dates / BR-004 Isolation
       └─ FR-001..FR-008  NFR-001..NFR-004
            └─ UC-001..UC-004 (Given/When/Then scenarios in srd.md)
                 └─ STORY-001..STORY-005 (MoSCoW grouped in stories.md)
                      └─ TASK-001..TASK-010 (Satisfies: FR-NNN in tasks.md)
```
