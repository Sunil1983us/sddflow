## 1. Overview
Investigation cases created by ICS on two triggers.
No automated resolution in Phase 1 — Operations team resolves manually.

## 2. Triggers

| Trigger | Status Set | Ring-Fence | EVT_002 | EVT_003 |
|---|---|---|---|---|
| RECONCILIATION_MISMATCH | RECONCILIATION_MISMATCH | RETAINED | NOT triggered | NOT triggered |
| RECEIPT_TIMEOUT | RECEIPT_TIMEOUT | RELEASED | NOT triggered | EVT_003 triggered |

## 3. Investigation Case Table

| Column | Type | Notes |
|---|---|---|
| investigation_id | UUID PK | Generated by ICS |
| payment_id | UUID FK | Reference to payments |
| correlation_id | VARCHAR(50) | For tracing |
| trigger | VARCHAR(30) | RECONCILIATION_MISMATCH or RECEIPT_TIMEOUT |
| status | VARCHAR(20) | OPEN (only value in Phase 1) |
| trigger_detail | TEXT | JSON — mismatched fields or timeout context |
| created_at | TIMESTAMP | UTC |
| resolved_at | TIMESTAMP | NULL in Phase 1 |
